# 📦 PWA App Toko (CRUD + Offline)

Aplikasi web toko sederhana berbasis **Progressive Web App (PWA)** dengan fitur CRUD dan dukungan offline.

## ✨ Fitur

* ✅ Menampilkan data barang (GET API)
* ✅ Menambah barang (POST API)
* ✅ Menghapus barang (DELETE API)
* ✅ Offline mode (localStorage caching)
* ✅ Install ke Desktop/Mobile (PWA)

## 🧪 Cara Menjalankan

1. Jalankan XAMPP (Apache & MySQL)
2. Letakkan project di:

   ```
   C:\xampp\htdocs\
   ```
3. Akses:

   ```
   http://localhost/app-toko
   ```

## 📁 Struktur Project

```
app-toko/   → Frontend (HTML, JS, PWA)
api-toko/   → Backend (PHP API)
```

## ⚠️ Catatan

Project ini menggunakan PHP sehingga tidak bisa dijalankan langsung di GitHub Pages.
